# 一瞥 · Glance 2.5.0

看一眼，就到了。为你的 Mac 制作的原生窗口切换器，适用于 Apple Silicon、macOS 14 及以上。无需账号，没有应用内网络请求或遥测。

2.0 由“窗间 · WindowHop”更名为“一瞥 · Glance”，并换上新的界面：

- **快速切换**：按住 ⌥ 再按 Tab，面板里只有窗口卡片和一行选中窗口的标题。卡片宽度跟着窗口的形状走，选中的那张用琥珀色描边并微微抬起。
- **停留**：松开后保持打开时（或固定面板），顶部出现工具栏：样式切换、窗口操作、固定和设置；卡片上显示 ⌘1–9 编号。
- **搜索**：左边是结果列表，匹配到的字（包括拼音和首字母）会高亮；右边是选中窗口的大图预览和操作按钮。搜索时面板尺寸固定。
- **设置**：七个分区；“切换方案”列表可以命名、新建和删除方案；修改即时生效，右上角可以撤销。
- **配色**：石墨与琥珀，浅色和深色主题都适配。

2.5 加入十项功能。这一版只在 GitHub Actions 上编译并跑过核心检查，还没有实机检查，见 [2.5 验证记录](VALIDATION-2.5.md)：

- **全局窗口快捷键**：不用打开面板，在任何应用里把当前窗口放到半屏、四分之一屏、三分之一屏或居中，还能还原。默认关闭，在 设置 › 搜索与按键 中打开。
- **切换列表里的设置窗口**：一瞥的设置窗口打开时，也能用 ⌥Tab 和搜索切回它。
- **记住最近使用顺序**：重启一瞥后顺序保留，重启电脑后按应用恢复。保存在单独的位置，不含窗口标题，不随设置导出。
- **更多浏览器**：标签页搜索支持 Safari、Chrome、Chrome Beta、Edge、Brave、Vivaldi、Opera 和 Arc。
- **搜索习惯**：同一个词反复选同一个结果，它会排到前面。只在本机保存搜索词和所选的应用，不存窗口标题，不随设置导出，可以关闭和清除。
- **Dock 预览补全**：中键关闭、右键菜单、预览图实时更新；悬停时在窗口原来的位置显示它的画面。这个画面是截图，不会把窗口提到前面。
- **中文搜索增强**：多音字（重庆、银行）、“微xin”这样中文和拼音混着输入、小鹤 / 自然码 / 微软双拼（默认关闭）、跳过中间的字（chrm 找到 Chrome）。
- **崩溃后自动重新打开**：约 2 秒后重新打开，10 分钟内已重开 3 次后不再重开。正常退出和强制退出不会重开。没有常驻的辅助进程，可以在 设置 › 通用 关闭。
- **完整开始菜单**：搜索里可以执行系统命令（锁定屏幕、睡眠、重新启动等）、按文件名查找主目录下的文件、计算算式（回车复制结果），结果最后还有网页搜索（百度、必应、Google、DuckDuckGo，也能识别网址）。网页搜索只在你选中这一行并回车时才交给默认浏览器，一瞥自己不联网；如果搜索没有其他结果，这一行就是唯一的结果，回车会打开它。重新启动、关机、退出登录和清空废纸篓都会先确认，第一次可能要允许“自动化”权限。在 设置 › 搜索与按键 中可以分别关闭。
- **窗口布局**：记下所有窗口的位置和大小，之后一次放回去，可以从设置、搜索或菜单栏图标的右键菜单恢复。换了屏幕时按比例换算。不打开没有运行的应用，不恢复前后顺序。保存时会记下窗口标题，用来区分同一个应用的多个窗口；布局只存在本机，不随设置导出。

2.3 加入两项 Windows 用户熟悉的功能：

- **Dock 预览**：指针在 Dock 的应用图标上停一下（默认 0.3 秒），图标上方就列出这个应用的窗口缩略图，像 Windows 任务栏一样；预览贴着 Dock 显示，应用名只在左上角出现一次。点按缩略图切换到那个窗口，悬停时点右上角的 × 关闭它；沿着 Dock 左右移动，预览直接换成旁边的应用；指针离开图标和预览、点按别处或打开切换面板时收起。Dock 放在左右两侧时，预览出现在图标旁边。在 设置 › 鼠标与触控板 › Dock 预览 中可以关闭、调整等待时间或不显示最小化的窗口。
- **搜索当开始菜单用**：一瞥的搜索里也能找到没有打开的应用和系统设置的各个页面，中文名、拼音、首字母和英文名都可以，例如“wx”或“wechat”找到微信，“蓝牙”“lanya”或“bluetooth”打开蓝牙设置，“wifi”打开 Wi‑Fi 设置。回车打开。匹配程度相同时，已经打开的窗口排在前面；每次最多列出 8 个可打开的项目。在 设置 › 搜索与按键 中可以分别关闭。

2.2 加入**菜单栏图标管理**（macOS 27 及以上），把 [Ice 2](https://github.com/teddychan/ice-2) 在 macOS 27 上能用的功能做进了一瞥：

- 在 设置 › 菜单栏 里把应用的图标拖进“显示”“隐藏”或“始终隐藏”。同一个应用的图标一起显示或隐藏；时钟、控制中心和 Siri 由系统管理，不能隐藏。
- 点按菜单栏里的一瞥图标显示“隐藏”组，按住 ⌥ 点按显示全部，右键点按打开一瞥菜单；也可以用快捷键（默认 ⌃⌥B、⌃⌥⇧B，需先在设置里打开），或把指针停在菜单栏空白处。指针离开菜单栏、菜单关闭后，图标按设置自动收回。
- 一瞥的搜索里可以找到菜单栏图标：输入应用名称或拼音，回车就打开它的菜单；隐藏的图标会先显示出来。
- 和 Ice 2 相比：不再每 15 秒读取一次菜单栏，只在应用启动、退出和打开设置页时读取；唤醒、切换桌面或显示器时直接替换隐藏请求，不会先把图标全部放出来再收起；不依赖任何第三方库。做法参照了 Ice 2（GPL-3.0）在 macOS 27 上使用的系统接口，代码是一瞥自己写的。
- macOS 26 及更早的系统没有这个接口，“菜单栏”页会说明需要 macOS 27。

2.1 适配 macOS 26 起的液态玻璃（Liquid Glass），并在 macOS 27 上实机检查：

- **切换面板与搜索**用系统的常规液态玻璃，文字随背后的明暗自动调整；卡片直接放在玻璃上，选中的卡片提亮并用琥珀色描边；卡片上的悬停按钮、窗口操作按钮都是玻璃胶囊。系统“液态玻璃”透明度滑块和“降低透明度”对一瞥同样生效。
- **设置窗口**用系统的侧栏、工具栏和分组表单，外观与“系统设置”一致；页面标题、“预览切换面板”和“撤销”在工具栏里。
- **应用图标**换成分层的液态玻璃图标，带玻璃高光和层次；macOS 14、15 继续用原来的平面图标。
- **强调色**：一瞥有了自己的琥珀色强调色，侧栏选中、开关和按钮都跟着变；在系统设置里选了其他强调色时，跟随你的选择。

功能沿用 1.6：AltTab 免费版与 Pro 版的主要能力、拼音搜索、浏览器标签页搜索、窗口整理、置顶和按应用分组等。逐项情况见 [功能对照](FEATURE-COMPARISON.md)，变更见 [更新记录](CHANGELOG.md)，验证范围见 [2.5 验证记录](VALIDATION-2.5.md)、[2.3 验证记录](VALIDATION-2.3.md)、[2.2 验证记录](VALIDATION-2.2.md)、[2.1 验证记录](VALIDATION-2.1.md) 和 [2.0 验证记录](VALIDATION-2.0.md)。

## 从窗间升级

- 应用标识沿用 `com.jethro.windowhop`，所以设置、置顶窗口和快捷键都会保留。
- 应用改名为 `Glance.app`（在中文系统中显示为“一瞥”）。把它放进“应用程序”，然后删除旧的 `WindowHop.app`。旧版正在运行时直接打开新版，新版会让旧版退出并接管。
- 如果已经用 `scripts/create-signing-identity.sh` 创建过签名证书，权限会保留；否则需要在“隐私与安全性”中为一瞥重新开启辅助功能和屏幕录制。
- 用过“登录时自动启动”的话，到 设置 › 通用 里关掉再打开一次，让它指向新的应用。

## 开始使用

打开“应用程序”里的 **一瞥**（`Glance.app`）。通过菜单栏图标进入“设置与权限”，双击正在运行的应用也能打开设置。

需要在系统设置的“隐私与安全”中开启辅助功能和屏幕录制。辅助功能用于控制所选窗口；屏幕录制用于缩略图，画面仅缓存于本机内存。后台预览默认关闭，开启后约每五秒更新最近列表的前十二项；前台窗口占满屏幕时暂停。

重新编译会改变本机签名。若权限开关已打开，但应用内仍显示未开启，需要移除旧的一瞥权限记录，重新添加当前 `/Applications/Glance.app`，再重新启动。

## 默认操作

| 按键 | 功能 |
| --- | --- |
| 按住 ⌥，按 Tab | 选择其他窗口；继续按 Tab 选择，松开 ⌥ 切换 |
| ⌥⇧Tab | 反向选择 |
| 按住触发修饰键时单按 Shift | 反向选择；可在操作页关闭，搜索编辑时保留 Shift 原用途 |
| ⌥` | 当前应用的窗口 |
| 直接输入文字 / ⌘F | 搜索并保持打开；⌘F 可选中已有查询重新输入 |
| ⌘V | 可从未打开搜索框的面板直接粘贴并搜索 |
| Return / Esc | 确认 / 取消 |
| Tab / ⇧Tab、方向键 | 面板内选择窗口 |
| Space | 打开 / 关闭大图预览 |
| ⌘M | 最小化 / 还原窗口 |
| ⌘⇧F | 全屏 / 退出全屏 |
| ⌘W | 请求关闭窗口，未保存内容由原应用处理 |
| ⌘Q | 请求退出选中应用，未保存内容由原应用处理 |
| ⌘H | 隐藏 / 显示选中应用 |
| ⌘1 … ⌘9 | 直接切换到第 1–9 个窗口；停留或搜索时卡片上会显示编号 |
| ⌃⌘← / ⌃⌘→ | 把选中窗口放到左 / 右半屏 |
| ⌃⌘↑ / ⌃⌘↓ | 填满屏幕 / 移到下一块屏幕 |
| ⌘P | 置顶 / 取消置顶选中窗口，置顶窗口排在当前窗口之后 |
| ↓ / Esc | “按应用合成一组”时展开 / 收起选中应用的窗口 |
| 把文件拖到卡片上 | 用该卡片的应用打开文件，并切换过去 |

搜索支持中文、完整拼音、拼音首字母、应用名、窗口标题、应用标识和多个关键词。名称精确匹配、前缀和包含匹配优先于拼音、首字母、标识和拼写容错；同等匹配按最近使用排序，清空查询恢复该组的原排序。四个字符起，英文或完整拼音可容忍一处错字、漏字、多字或相邻字母颠倒。排序与容错均可关闭。多音字的常见读音都能匹配，中文和拼音可以混着输入，也可以跳过中间的字，并可选双拼方案。

默认 W、Q、M、F、H 等普通字母直接用于搜索，操作窗口使用 ⌘ 组合或按钮。在 设置 › 搜索与按键 可切回“传统单键操作”，使用原来的单键操作与 S 搜索；已有按键配置保留，明确录制的组合在两种模式中均可使用。搜索框保留系统文字输入、光标和选区编辑、复制粘贴；实体输入法组合文字仍需实机确认。缩略图卡片按行排列，上下方向键选到相邻行中位置最接近的卡片；图标和列表样式的上下导航保持同一列，并自动滚动到选中窗口。

打开时先显示上次的窗口列表及已有预览，再校验最新窗口。校验最多等 0.3 秒，没有回应的应用暂时保留上次的窗口，回应后再更新。选择如果还是按键自动定位的，会按最新列表重新定位；手动改过的选择不变。快速松键或回车会等待校验，并保留原先选择的窗口编号；目标已关闭时提示重新选择。预览优先捕获选中窗口和实际可见卡片，滚动时再请求后面的窗口；最多同时执行两次截图，关闭面板会丢弃未开始和过期的请求。图片缓存最多六十四项、估计三十二 MiB；这个限制不是整个应用的内存上限。

已授权时，只有取得有效辅助功能窗口对象的窗口参与切换；系统为已关闭设置页、旧窗口及辅助界面保留的画面不再混入列表。读窗口失败不会被当成“无窗口应用”。切换失败时保留选择并显示原因；面板打开期间额外接收取消按键，普通瞬时面板每 50 毫秒核对松键状态，搜索、固定、演示和手势不受该检查影响。再次触发快捷键会取消上一轮待提交的切换，面板关闭后停止按键接收和松键检查。

通过应用及窗口通知跟踪关闭、最小化与前台变化，不监听窗口移动和缩放。标题只在面板打开时跟踪，最多每 0.1 秒合并更新一次。仅面板打开时每十秒兜底枚举一次，覆盖不提供通知的应用。面板关闭时没有定时器，只在新窗口、最小化和还原、应用启动和退出、隐藏和显示、切换桌面之后刷新一次列表，最多每秒一次。已销毁窗口可直接从空闲缓存移除。悬停缩略图卡片会显示小型窗口操作按钮；面板停留时，顶部工具栏提供最小化、关闭和“更多”菜单（全屏、窗口位置、置顶、隐藏、退出应用）；右键卡片也有同样的菜单。窗口操作会显示请求结果；遇到无法切换的窗口时保留面板，可继续选择其他窗口。关闭或退出应用时，未保存内容仍由原应用确认。

置顶记住应用和窗口标题（保存在本机设置里，不随设置导出），应用或电脑重启后按标题找回窗口；同名窗口不止一个时不猜，等能确定时再生效。浏览器标签页切换前会核对网址，标签页已关闭时面板保留并提示。打开面板时设置窗口会暂时收起：按 Esc 取消或演示结束后回到前面，切换到别的窗口后留在它后面，从菜单栏或重新打开一瞥都能回到它。

默认启用“全部窗口”（⌥⇥）和“当前应用”（⌥`）两个方案；在 设置 › 切换方案 中点“新建方案”可以再加，最多九个，新方案会自动避开已占用的快捷键。升级保留已有配置。参考 AltTab 默认设置：最近使用、自适应缩略图、系统主题、100 毫秒延迟、活动窗口所在屏幕、鼠标悬停选择关闭；显示最小化、隐藏及全屏窗口，无窗口应用列在末尾，访达无窗口时隐藏。

## 设置

修改即时生效，页面标题下方显示“修改已生效，可以撤销”，工具栏右侧出现“撤销”，撤销会回到打开设置时的状态。设置无效（例如两个方案用了同一个快捷键）时不会生效，页面顶部会说明原因，可以直接“放弃这项修改”。每次打开设置后的第一处修改之前，会自动备份当时的设置；读取时遇到无效设置会逐项修正，而不是整份回到默认。

- **切换方案**：左边是方案列表，每张卡片显示名称、快捷键和摘要（例如“所有应用 · 最近使用 · 松开切换”）；可以新建、命名和删除。右边编辑选中的方案：快捷键、松开后的行为、应用 / 桌面 / 屏幕范围、四类窗口的显示 / 隐藏 / 放末尾、排序、应用分组、系统标签页，以及独立的样式、主题和尺寸。开启触控板手势后，列表里也会出现“触控板”方案。
- **搜索与按键**：直接搜索 / 传统输入、搜索提示、名称优先与拼写容错、常选结果靠前、跳字匹配和双拼、浏览器标签页、未打开的应用和系统设置页面、系统命令、文件、算式、网页搜索、单 Shift 反向选择、方向键、Vim 导航、可录制的面板操作按键、全局窗口快捷键和窗口布局。
- **外观与预览**：三种样式、主题、标题显示和截断、自动尺寸、状态图标、桌面编号、悬停按钮、Dock 角标、⌘1–9 编号、预览、显示屏幕、延迟与动画。
- **鼠标与触控板**：Dock 预览（开关、显示前等待、是否包含最小化窗口、实时更新预览图、悬停时在窗口原来的位置显示）、鼠标悬停选择、切换后移动光标、三 / 四指手势与系统手势冲突提示、实验性的手势拦截、独立的触控板方案、震动反馈。
- **例外**：按运行中的应用或应用文件添加规则，设置始终隐藏、无窗口隐藏或匹配标题；指定应用中或全屏时让出全局快捷键。保留逐行关键词排除。UU 远程默认在系统全屏时让出快捷键，窗口模式保留 ⌥Tab。
- **权限**：检查系统授权、打开对应设置、查看演示；首次启动时显示三步入门引导。
- **菜单栏**（macOS 27 及以上）：把菜单栏图标分到“显示 / 隐藏 / 始终隐藏”，拖动或右键换组；指针悬停显示（前台窗口占满屏幕时暂停，点按一瞥图标照常可用）、自动收回时间、两个快捷键，以及是否在搜索中包含菜单栏图标。辅助功能权限用于读取菜单栏里有哪些图标。
- **通用**：切换窗口的方式（系统窗口服务 / 辅助功能接口）、VoiceOver 时保持面板打开、菜单栏图标、登录启动、意外退出后自动重新打开、命令行开关，以及设置的导出、导入、恢复到上次修改前和恢复全部默认。

侧栏可以查找具体选项，支持多关键词、拼音和常用英文名称，找到后自动滚动并用琥珀色框标出。面板右上角的设置按钮可直接进入设置。左上角按钮可以收起或展开侧栏，工具栏右侧的播放按钮可以预览示例切换面板。登录启动的开关立即生效。未启用的方案不占用快捷键；应用例外中的“不响应”会注销组合，将按键交还给当前应用。固定面板打开时仍跟踪前台应用与全屏状态，同时暂停最近使用历史更新，以保持面板排序稳定。

录制组合时可只按修饰键，全部抬起后完成；Esc 取消。全局组合需要包含 ⌥、⌃ 或 ⌘，避免只用 Shift 占用正常文字输入；面板操作可明确配置为纯修饰键。修饰键导航的重复按键跟随系统速度，抬手、其他输入、搜索或收起面板会停止重复。

VoiceOver 焦点跟随选中窗口，提供位置、数量和最小化、全屏、关闭、隐藏等辅助功能操作。默认 VoiceOver 开启时，松开触发键后保持面板打开。点击面板外部取消切换；选择无窗口应用时重新打开该应用。系统减少动态效果时关闭淡入淡出。

## 兼容范围

液态玻璃界面已在 macOS 27.0.1 上实机截图检查（每个设置页、三种面板样式和搜索，浅色与深色）。macOS 26 和 macOS 14–15 的分支经过代码检查，尚未在对应系统实测；降低透明度、增强对比度和图标的“着色 / 透明”样式也还没有逐项切换系统设置验收。

桌面归属和窗口编号优先使用动态加载的系统接口；缺少接口时退回公开的可见窗口信息，无法查询的桌面不显示编号。系统更新可能影响这些接口。窗口最小化或隐藏时是否能取得桌面编号，也依赖系统结果。

系统标签页仅支持应用通过辅助功能暴露的标签组，不保证浏览器网页标签页或自绘标签控件可用。未选中的标签页无法单独关闭，切到标签页后可在原应用中关闭；预览来自它所属的实际窗口。

“最近创建”按一瞥首次发现窗口的时间记录。刚启动时已有窗口的实际创建时间无法追溯。无法取得有效窗口控制对象的画面不参加精确窗口切换；应用暂时未暴露的跨桌面窗口也可能不可见，需要具体应用与 Spaces 环境确认。

从未生成预览的最小化窗口显示图标。已有预览可继续保留，受系统保护的内容可能无法捕获。开启后台预览也不能保证获取每个最小化窗口的新画面。

触控板手势默认关闭。系统自己的三指、四指手势会先于一瞥识别，所以选择手势后，一瞥会读取系统触控板设置并提示冲突的手势，附“打开触控板设置”按钮。“尝试拦截已识别的手势”保留为实验性选项、默认关闭；偏离指定方向、四指系统手势中途变三指等情况会拒绝触发。实际效果仍需实体触控板验证。

多屏、系统 Spaces、完整 VoiceOver / 粘滞键和不同应用标签页还需对应环境确认。详细记录见 [验证记录](VALIDATION.md)，旧版结果保留在 [1.4.1 验证](VALIDATION-1.4.1.md) 和 [1.3 验证](VALIDATION-1.3.md)。当前不提供完整 21 语言界面、Intel 交付、macOS 12 支持、在线更新及反馈服务。

## 命令行

命令行接口默认关闭：开启后，本机任何程序都能通过它读到所有窗口标题并切换窗口，而不需要自己申请权限。需要时在 设置 › 通用 中打开“允许命令行列出和切换窗口”，再执行：

```sh
/Applications/Glance.app/Contents/MacOS/Glance --list
/Applications/Glance.app/Contents/MacOS/Glance --diagnostics
/Applications/Glance.app/Contents/MacOS/Glance --focus 'cg:123'
```

`--list` 和 `--detailed-list` 输出 JSON，`--focus` 使用列表中的 `id`。命令通过本机消息端口由已授权的运行实例处理，不需要另一个程序获得窗口权限；`--help` 查看说明。

`--diagnostics` 返回当前运行的权限、快捷键状态、预览预算、队列数量、活动定时器、面板输入状态、窗口观察器和各类通知计数，以及耗时的 P50 / P95。窗口发现诊断统计被过滤的残留画面和读取失败数量，以及超过等待时间才回应的次数（`lateScans`）和面板关闭时的列表刷新次数（`idleRefreshes`）。`quickRelease` 统计快速松键时直接切换（`atOnce`）和等了最新列表（`waited`）的次数；`frontFullscreen` 和 `hoverMonitor` 显示前台是否占满屏幕、悬停监听是否开着。`windowShortcuts`、`recentOrder`、`searchHabits`、`layouts` 和 `crashRestart` 只有数量和状态。耗时每类最多保存一百二十个样本，仅在内存中，不包含窗口标题、输入文字或图像。`panel_ordered` 表示调用显示面板的时刻，包含配置的显示延迟，不是显示器实际出帧或实体按键的完整延迟。低电量模式下，选中预览和已开启的后台预览更新间隔翻倍；睡眠时停止截图和活动定时器。

窗口不存在或聚焦失败时，`--focus` 输出错误 JSON 并返回非零状态码。重复启动会连接已有实例；菜单中的“重新启动一瞥”会等待旧实例退出后再接管快捷键和命令端口。

## 源码与构建

`Sources/` 是完整源码，`Tests/CoreTests.swift` 的九百三十六项检查覆盖算式、网页地址、文件筛选、系统命令、窗口布局、崩溃重开、多音字和双拼、搜索习惯、浏览器脚本、最近使用顺序、窗口快捷键、未打开的应用与设置页的搜索和排序、Dock 预览设置、菜单栏图标的分组与允许列表、搜索、匹配高亮、筛选、排序、分组、例外、配置迁移与修复、导入导出、方案命名与新建、面板输入、连续触发与松键逻辑、独立手势、活动定时器、窗口资格和残留过滤、置顶与按应用分组、浏览器标签页筛选、窗口整理、流式卡片布局、面板尺寸、具体设置查找与三种布局。`AppDelegate` 只负责面板会话，预览在 `AppDelegate+Preview.swift`，拖放、角标、置顶、标签页等在 `AppDelegate+Features.swift` 与 `SystemIntegration.swift`；界面在 `SwitcherUI.swift`、`SettingsUI.swift`，配色在 `DesignSystem.swift`；菜单栏图标的规则在 `MenuBarCore.swift`，读取、隐藏和显示在 `MenuBarController.swift`，设置页在 `MenuBarSettingsUI.swift`；Dock 预览在 `DockPreview.swift` 与 `AppDelegate+DockPreview.swift`，可打开的应用、设置页和文件搜索在 `Launcher.swift`。macOS 26 起的液态玻璃图标是 `Resources/AppIcon.icon`（Icon Composer 格式：`icon.json` 加分层 SVG），旧系统用的平面图标由 `Resources/Icon.swift` 在编译时绘制；琥珀色强调色在 `Resources/Assets.xcassets`。使用 Swift、AppKit、SwiftUI、ScreenCaptureKit 和系统辅助功能接口，无第三方依赖。

主线程不等其他应用：面板的按键拦截在自己的线程上，按主线程最近公布的状态回答（`PanelInputMonitor.swift`）；应用和窗口的通知、当前窗口的读取在 `WindowEngine` 的辅助功能线程上；切换和窗口操作在 `WindowControl` 的动作队列上。主线程不同步等待它们，反过来只有让出前台（`NSApp.yieldActivation`）这一步由动作队列同步等主线程。Dock 预览的切换和关闭也在动作队列上；手势拦截和读取 Dock 图标仍在主线程。

`Tests/SearchBenchmark.swift` 可独立编译测量三十至六百个模拟窗口的筛选耗时；测量边界与结果见验证记录。

安装 Command Line Tools 后执行 `./build.sh`，会先运行检查，再生成 `Glance.app`。装有完整 Xcode 时，还会用其中的 actool 编译液态玻璃图标和强调色；只有 Command Line Tools 时跳过这一步，使用平面图标和系统强调色。当前构建用于自己的 Mac，未提供自动更新或发布服务。

也可以在访达中双击 `build-and-log.command`，它会运行 `build.sh` 并把完整输出（连同系统和 SDK 版本）写入 `build.log`。

推送到 `main` 或开 Pull Request 时，GitHub Actions 会在 macOS 27 上运行 `build.sh`（`.github/workflows/build.yml`，只改 Markdown 时跳过），并把 `Glance.app` 的压缩包保留七天。它验证能否编译和核心检查，没有真实窗口和权限，测不了实际切换。它还会启动构建好的应用，从外部发送崩溃信号，检查重开是否正常（`scripts/crash-restart-check.sh`）。那个压缩包是临时签名的，运行它要重新授权；自己用 `build.sh` 和本地证书构建可以保留已有的授权。

`scripts/menubar-selftest.command` 用已编译的一瞥临时隐藏一个菜单栏应用几秒钟，逐步检查隐藏、显示、始终隐藏和显示全部，结果写入 `menubar-selftest.json`，不保存任何设置；`scripts/menubar-probe.command` 记录菜单栏在辅助功能里的结构，用于排查新系统上的变化。

隐藏菜单栏图标用到 macOS 27 的私有框架 MenuBarClientCore，通过 `Sources/Bridge/MenuBarBridge.m` 在运行时查找并调用，编译时不链接；找不到接口、系统拒绝或 5 秒内没有回应时，所有图标恢复显示。

检查界面时可以双击 `scripts/ui-snapshots.command`：编译后用示例窗口依次打开每个设置页、三种面板样式和搜索（浅色、深色各一套），把图片和图标存进 `ui-snapshots` 文件夹，约半分钟，期间会抢到前台。它只截一瞥自己的窗口，背后垫一张示意背景，不会录下屏幕上的其他内容；对应的启动参数是 `--ui-snapshots <文件夹>`。

**让重新编译不再丢权限**：先运行一次 `./scripts/create-signing-identity.sh`，它在登录钥匙串里创建只用于代码签名的本机证书“WindowHop Local Signing”（需要输入一次登录密码；沿用旧名，改名前创建的证书继续有效）。之后 `build.sh` 会自动用它签名，系统就能在每次编译后继续认得一瞥；没有证书时仍退回临时签名并给出提示。换成新证书后需要再授权一次。
